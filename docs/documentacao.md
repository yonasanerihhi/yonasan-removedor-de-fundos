## 1. Visão geral

O **Remover de Fundos** é um removedor de fundo de imagens que roda **inteiramente no navegador**.  
Não há upload para servidor: as imagens nunca saem do seu dispositivo.

### Recursos principais

| Recurso | Descrição |
|--------|-----------|
| Modo Automático | Detecta o fundo sozinho (incluindo xadrez falso de PNG) |
| Selecionar fundo | Você clica nas cores que quer remover |
| Estúdio | Varinha mágica, pincel de apagar/restaurar, recorte e refinamento de bordas |
| Múltiplas imagens | Processa várias de uma vez e baixa em arquivos separados ou ZIP |
| Fundo no download | Transparente ou cores sólidas (verde, branco, etc.) |
| Histórico | Desfazer / refazer / resetar |

---

## 2. Privacidade e dados

- **Processamento local**: todo o trabalho (remoção de fundo, pincéis, recorte) acontece no JavaScript do navegador, usando Canvas.
- **Nenhuma imagem é enviada** a qualquer servidor do autor ou de terceiros.
- **Não armazenamos** arquivos, histórico de edições nem dados das fotos.
- Opcionalmente é usado **Google Analytics** apenas para medir acessos e cliques de forma anônima (páginas vistas, botões de apoio). Isso não inclui o conteúdo das imagens.

Você pode usar a ferramenta com tranquilidade para imagens pessoais, de trabalho, de IA ou qualquer material para o qual tenha direito de uso.

## 5. Como usar (resumo)

1. Arraste, cole (Ctrl+V) ou escolha uma ou várias imagens.
2. Escolha o modo:
   - **Automático**: costuma bastar; ajuste a tolerância se precisar.
   - **Selecionar fundo**: clique em “Selecionar na imagem” e toque nas cores do fundo.
   - **Estúdio**: use varinha, pincéis, recorte e botões de refinar borda.
3. Baixe o PNG (ou todas as imagens / ZIP se processou várias).

Dica: no modo Estúdio, “Cortar vazio” remove as margens transparentes automaticamente.
