# Remover de Fundos – Criado por Yonasan

Ferramenta **grátis** e **100% local no navegador** para remover o fundo de imagens.  
Detecta xadrez falso de PNG, permite seleção manual de cores, pincel, recorte e refinamento de bordas.

**Criada por [Yonasan](https://www.youtube.com/@YonasanErihhi/)**

---

## 🚀 Usar agora

**👉 [Abrir a ferramenta](https://yonasanerihhi.github.io/yonasan-removedor-de-fundos/)**

Ou abra o arquivo `index.html` no seu navegador — funciona offline também.

---

## ✨ O que dá para fazer

- Remoção automática de fundo (incluindo xadrez de PNG)
- Seleção manual das cores do fundo
- Modo Estúdio: varinha, apagar, restaurar, recortar
- Refinar bordas (contrair / expandir / suavizar)
- Processar várias imagens de uma vez e baixar em ZIP
- Fundo transparente ou cores sólidas no download
- **Nada é enviado a servidor** — tudo roda no seu navegador

---

## 🔒 Privacidade e uso

- Você pode subir imagens suas, de IA ou com licença/autorização.
- O processamento é local: nenhuma foto fica guardada em servidor.
- A ferramenta é grátis para usar. Pedimos apenas que não seja copiada e apresentada como criação de outra pessoa, nem que a imagem/nome do canal sejam usados para enganar alguém.

Termos completos: botão **Termos de Uso** no rodapé do site.
